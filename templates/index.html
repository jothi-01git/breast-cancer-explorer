Protein–Protein Interaction Analysis

Breast Cancer Protein Association Network

STRING

The top 10 breast cancer-associated genes identified using Open Targets were mapped to their corresponding human proteins and analyzed using the STRING database. The network represents functional associations among the selected proteins based on available evidence.

Explore the Network in STRING

The generated protein association network was obtained using the following top 10 breast cancer-associated proteins:

  1. BRCA2
  2. BRCA1
  3. PIK3CA
  4. PALB2
  5. CHEK2
  6. TP53
  7. ESR1
  8. ATM
  9. AKT1
  10. ERBB2

Recommended STRING analysis:

Search for BRCA2 and add the remaining proteins listed above. Select the organism as Homo sapiens. Then click Continue and wait for the network to appear.

The STRING results page provides additional information about protein associations, interaction evidence, confidence scores and network analysis.

Open STRING Database →

STRING networks can represent both physical and functional protein associations. The STRING score represents confidence in an association rather than direct binding strength.
